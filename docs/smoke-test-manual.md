# 人工冒烟测试流程表（博客平台）

> 适用范围：blog-platform 全栈系统（Spring Boot 后端 + Vue3 前端）
> 约定地址：后端 `http://localhost:8080`，前端 `http://localhost:5173`，API 基址 `http://localhost:8080/api`
> 用法：每项按「操作 / 预期结果」执行，在「结果」列打勾或记录异常。

---

| # | 模块 | 操作 / 输入 | 预期结果 | 结果 |

## 2. 文章发布与管理

| # | 模块 | 操作 / 输入 | 预期结果 | 结果 |
|---|------|------------|----------|------|
| 2.1 | 发布文章 | `/publish`：填标题、正文 → 点「发布文章」 | 发布成功，跳转到文章详情页，ES 立即可搜（无需等定时任务） | ☐ |
| 2.2 | 存草稿 | 填标题、正文 → 点「存草稿」 | 提示「草稿已保存」，跳转个人中心；列表中不展示（status=0），编辑页有草稿提醒条 | ☐ |
| 2.3 | 我的文章 | `/profile`「我的文章」 | 能看到自己全部文章，状态列区分「草稿 / 已发布 / 已隐藏」 | ☐ |
| 2.4 | 编辑文章 | 进入 `/publish/{id}` 修改标题 → 保存 | 详情页标题更新，作者可编辑；草稿可在此直接「发布文章」 | ☐ |
| 2.5 | 编辑数据 | 直接 GET `/api/articles/{id}/edit-data` | 返回该文章完整可编辑数据 | ☐ |
| 2.6 | 删除文章 | 删除自己一篇文章 | **硬删除**：文章及评论/点赞/收藏/通知全部物理删除且不可恢复 | ☐ |
| 2.7 | 越权编辑 | 用另一账号尝试编辑/删除他人文章 | 被拒绝（403 / 无权限提示） | ☐ |
| 2.8 | 隐藏文章 | `/profile` 点「隐藏」 | 状态变「已隐藏」：他人列表/搜索/详情均不可见（404），ES 文档同步移除 | ☐ |
| 2.9 | 重新公开 | 对已隐藏文章点「公开」 | 恢复「已发布」，ES 重建索引可搜 | ☐ |

### 备注
- 若某步「结果」异常，记录：页面现象 + 浏览器 Console 报错 + 后端日志堆栈，便于定位。
- 后端关键日志位置：Spring Boot 控制台 / `logs/`；MQ 死信队列 `blog.notify.dlq` 用于排查通知丢失。
- 计数（浏览/赞/评论/收藏）为「最终一致」，短时间内偏差属预期，需等定时任务刷回 DB。
